# 更懂你（Understand you better）

让 AI 更像「先懂你，再动手」的同事：任务开始前先猜你的真实目的、必须提出带猜想的问题、按目的切换到合适的专家视角，并在动手前点出容易出错的地方。

这是一个 **DSH Host 插件（bundle）**，只往 system prompt 里加文本，不注册工具、不改工具权限、不写会话日志、不联网。

## 它做什么

装上之后，处理任务型请求时 AI 会按这个顺序工作：

1. **先猜目的**：给出 1~3 个最可能的真实目的，标出最可能的那一个（落到「你最终想拿到什么结果」，不是复述你的字面问题）。
2. **必须提问**：围绕「猜得对不对」和「会改变结果的关键选择」，提 1~2 个问题。每个问题都先写出它自己的猜想和默认答案，让你能直接回「对」或「不对」。
3. **选专家视角**：按目的切换成对应的专家（架构师、代码审校、数据分析师、产品经理、安全工程师……），用那个角色的标准和检查清单办事，但保留原本的身份和语气。
4. **点出易错点**：给出结论或动手之前，用简短清单列出 1~3 个最容易出错的地方，并说明怎么避开。
5. **收尾回扣**：结束时说明按哪个目的做的、采用了什么假设、还有什么要你确认。

另外两个可选能力：

- **关于用户**：在配置里写一段自己的长期偏好（语言、习惯、禁忌、项目背景），插件会把它作为独立 section 注入，每个会话都带着。
- **每步提醒**：在离用户消息最近的运行时上下文里放一行短提醒，避免长 prompt 把协议冲淡。

**默认不打扰闲聊**：打招呼、情绪回应、一句话能答的事实问题不触发这套流程。

## 装上之后大概长这样

你：帮我弄一下登录

AI：
> 我猜你是想让登录能正常跑起来，最可能是想修一个具体报错；也可能是想先把登录骨架搭出来，或者想换一种登录方式。
>
> 先确认两件事（我猜错了直接说）：
> 1. 我猜是「已经有报错，想定位并修掉」，对吗？不是的话，是「还没开始写」还是「写完了想接第三方」？
> 2. 我猜你现在最在意能不能跑通，暂时不管样式和并发，对吗？
>
> 我按后端架构师 + 安全审校的视角来看。这里最容易错的三处：……

## 安装

1. 打开 DSH 的 **Plugins / 插件管理**，点 **Add plugin（添加插件）**。
2. 选择本地目录：

   `D:\Users\Documents\deepseek-harness\default-workspace\dsh-understand-you`

3. 安装完成后，列表里会出现「更懂你」，图标是蓝色气泡问号，默认启用。
4. 安装后用**新会话**验证；已经打开着的会话可能不会立刻带上新 prompt。
5. 想关掉时，在插件列表里禁用或移除即可，`cordis.patch.yml` 不用手动改。

> 本地目录安装是链接安装：改这个目录里的文件后，重启 DSH 生效。

## 配置

所有字段都有默认值，只写想改的即可：

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `language` | `zh` / `en` | `zh` | 内置协议文本的语言（不影响 AI 用什么语言回答你） |
| `profile` | 字符串 | 空 | 「关于用户」长期偏好，非空才会注入 |
| `requireQuestion` | 布尔 | `true` | 是否强制执行「必须提问」 |
| `maxQuestions` | 1~3 | `2` | 每轮最多提几个问题 |
| `expertPerspective` | 布尔 | `true` | 是否按目的切换专家视角 |
| `pitfalls` | 布尔 | `true` | 是否点出易错点 |
| `casualExempt` | 布尔 | `true` | 纯闲聊是否豁免 |
| `reminder` | 布尔 | `true` | 是否每步注入一行短提醒 |
| `extra` | 字符串 | 空 | 追加的自定义规则，会附在协议末尾 |

### 改配置

在 profile 的 `cordis.patch.yml`（桌面版是 `C:\Users\你的用户名\.dsh\profiles\desktop\cordis.patch.yml`）末尾追加一段覆盖：

```yaml
- id: dsh-understand-you
  config:
    profile: |
      我在 Windows 上用 DSH，习惯先给结论再解释，回答尽量短。
      项目是 TypeScript + React，不要用 JavaScript 举例。
    maxQuestions: 1
    reminder: true
```

覆盖会整段替换这个行的 config，但插件对缺省字段有默认值，所以只写想改的几项就行。改完重启 DSH。

## 怎么确认生效

1. 插件列表里有「更懂你」，状态是启用，图标能正常显示。
2. 新开会话，发一个模糊任务（例如「帮我弄一下登录」）：应该先看到目的猜想和 1~2 个带猜想的问题，而不是直接开干。
3. 发一句闲聊（例如「在吗」）：不应该被逼着走流程。
4. 想间接确认，可以把配置改成 `language: en` 并重启，再开新会话：AI 的流程措辞会变成英文协议的痕迹。

## 设计说明与边界

- **只加 prompt，不强制行为**：它告诉模型该怎么做，但不拦工具、不阻塞执行；模型仍可能不照做。想要硬约束得另做工具或守卫，那是另一个插件。
- **不改变身份**：协议里明确写了「与已有角色设定、工作区指令冲突时以它们为准」，所以不会把你原本的人设（比如 AGENTS.md 里那条鱼）改成通用助手。
- **先回答再追问**：你直接提问时，AI 应该先回答再补一个确认性问题，而不是用反问糊弄过去；这条也写进协议了。
- **默认闲聊豁免**：避免「在吗」也被要求回答三个问题。
- **token 成本**：协议正文约 900 字，每步都会在 system prompt 里出现；`reminder` 再占 78 字。很在意 token 可以把 `reminder` 关掉，或把 `extra` 留空。
- **不写会话日志、不联网、不读你的数据**：插件只在启动时注册 prompt section 和运行时 context。

## 卸载

插件列表里移除「更懂你」，或者从 profile 的 bundle 列表里移除。插件行和 prompt 文本一起消失，不留状态。
